# roadmind_library
Python-библиотека для анализа дорожного видеопотока с использованием компьютерного зрения. Обнаружение и отслеживание транспортных средств, извлечение траекторий и анализ транспортных потоков на основе YOLO, ByteTrack, OpenCV

# Библиотека будет улучшаться и обогащаться новым функционалом в зависимости от своб. времени
